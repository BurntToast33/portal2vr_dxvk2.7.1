V0.2.1
Done:
- Fixed some maps setting an invalid render state when compositing the HUD onto the spectator camera, causing a black screen.
- Fixed a bug where VR loses textures after a device reset.
- Fixed the viewmodel FOV.
- Disabled MSAA due to it currently being broken.

- Added levels to the debug command `-vrdebug`. `-vrdebug 1` opens the console, while `-vrdebug 2/3/4` adds more detail about what is happening.
- Added smooth rotation through portals by VittorioRomeo.
- Added Portal: Reloaded support.
- Added built cubemaps to background maps.
- Added a roll bump to smooth rotation to handle 180-degree upside-down cases.

- Added a utility tool to hook anywhere in a function and dump CPU registers.
- Overhauled how background files are parsed to prepare for mapping cubemaps to loading zones in the future.
- Overhauled the input binding system to make adding and modifying binds easier.
- Changed the upright rotation model for smooth rotation from SLERP to NLERP. 
  The difference is a slight speed difference and angle drift, which is not noticeable at default settings, while improving performance.
